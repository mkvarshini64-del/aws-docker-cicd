# Travel Explorer - AWS DevOps Project

## Project Overview

Travel Explorer is a simple web application that will be containerized
using Docker and deployed on AWS.

The project demonstrates a complete DevOps workflow including Git,
GitHub, Docker, Jenkins CI/CD, AWS EC2, Application Load Balancer,
Auto Scaling, CloudWatch and Route 53.
